# session10 — training_loop

`uv`-managed project for the Session 10 assignment. The writeup with results
lives one level up in [`../README.md`](../README.md); this file is how to run it.

## Setup

```bash
uv sync
```

`torch` is pulled from the PyTorch cu124 index (see `pyproject.toml`); on a
CPU-only box it still works, just slower.

## Check it executes (fast, CPU)

```bash
uv run python dry_run.py
```

Sets `S10_SMOKE=1` and hides the GPU: tiny model, small data subset, ~50 steps
per experiment. Runs in 1–2 minutes and executes every code cell in the
notebook.

## Full run (GPU box)

```bash
# optional: tell the MFU cell your card's real bf16 peak
export S10_PEAK_TFLOPS=989          # H100 SXM; A100=312, RTX A6000=155, ...

uv run jupyter nbconvert --to notebook --execute --inplace session10_training_loop.ipynb
```

Regenerate the notebook from source after editing `src/trainloop/`:

```bash
uv run python build_notebook.py
```

## Layout

`src/trainloop/` is **plumbing only** — the architecture and the data loading.
Every experiment (shapes, gradient check, accumulation, grad norm, MFU, the
float breakdown) is written out and run step by step in the notebook cells.

| path | what it is |
| --- | --- |
| `src/trainloop/model.py` | the compact nanoGPT decoder |
| `src/trainloop/data.py` | char-level Tiny Shakespeare + fixed and variable-length batch samplers |
| `src/trainloop/utils.py` | seeding, device pick, the `S10_SMOKE` switch |
| `session10_training_loop.ipynb` | tasks 1–6, done by hand, one section each |
| `build_notebook.py` | regenerates the `.ipynb` from its `CELLS` list |
| `assets/` | plots + `results.json`, regenerated by a run |
