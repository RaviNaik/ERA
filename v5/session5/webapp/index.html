⚡ Warmup Band — Gradient Stability
At the pretrain → anneal boundary, a 3B-token 60/40 warmup band is inserted. 60% old mixture, 40% anneal mixture, ramped over 3 billion tokens before the full anneal composition takes over. This prevents gradient norm explosion — the V4 Hindi embedding spike reached 150× baseline without this band. Embeddings are explicitly unfrozen at every mixture seam.

Synthesis Strategy

Tier 1 — One-shot function calls from OpenAPI schemas: 40B tokens

Tier 2 — Multi-turn tool-use conversations: 15B tokens

Tier 3 — Long trajectory rollouts (anneal-only): ~4.4B tokens

⚠️ Tool observations always masked in loss. Applying loss to tool returns would teach the model to hallucinate environment state.
06 / 08 · REASONING DEPTH

Difficulty & Reasoning-Length Bands

The effort dial (low / medium / high / ultra) is learned, not created at inference. The model can only produce different reasoning depths if it saw examples across this full range during training.

08 / 08 · PROXY EXPERIMENT

Proxy Runs at 1B and 3B Scale

A trillion-token decision should not be based on intuition. The 1B proxy costs ~$200, takes ~4 hours, and ranks competing recipes reliably before any of them is trusted at full scale.

Ablation Variants — 1B × 30B tokens
3B Follow-up Run
If the 1B proxy endorses variant A, a 3B parameter / 100B token run confirms the mix scales. The 3B run also tests the anneal reserve composition using a 2% anneal of 2B tokens. Cost: ~$2,000 · Duration: ~2 days.
