🇮🇳 ERA V5 · Session 12 Assignment

32 Virtual GPUs, and what ZeRO actually shards

Data parallelism replicates the model and averages gradients — simple, but memory never improves. ZeRO removes that redundancy one state category at a time: optimizer state (stage 1), gradients (stage 2), then parameters themselves (stage 3). Every number on this page is either the closed-form formula or a measurement from 32 real torch.distributed CPU processes — no GPU anywhere in this project.

Real, not simulated. The 32 "ranks" below are genuine operating-system processes joining a real process group (backend: gloo) and exchanging real tensors over real collectives. Every byte in the results table was read off those tensors after a real distributed step, then cross-checked against the closed-form formula. See parallelization_experiments/ for the full notebook and test suite.
