07 / 08 · RECONSTRUCTION PROOF

Checkpoints, Fork & Replay

Each checkpoint binds model weights + optimizer state + RNG state + ledger offset. After the crash, resume loads that checkpoint and verifies the next batch ID and hash match exactly. Forking clones a checkpoint into a new branch.
